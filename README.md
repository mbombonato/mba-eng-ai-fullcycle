Cada pasta é um desafio independente. Ela começa com o conteúdo do repositório base fornecido
pela Full Cycle (equivalente ao fork pedido no enunciado) e contém o enunciado original em
`ENUNCIADO.md`, além do `README.md` próprio com as instruções de execução.

## Como avaliar

Entre na pasta do desafio e siga o `README.md` dela. Variáveis de ambiente ficam em `.env`
(nunca versionado), criado a partir do `.env.example` de cada projeto.
